# Agent Handbook — corrections and source requests

This repository is the public feedback channel for **codingagenthandbook.com**, a small handbook about AI coding agents (Codex, Claude Code, Cursor).

Use it to:

- **Report a fact that is wrong or out of date** — include the page URL, the sentence, and the correct value with a source.
- **Ask for the source** behind a claim we make.
- **Request a page** on a failure mode we have not covered.

What helps most: a date and a link. Most numbers on the site are captured snapshots (prices, version numbers, issue counts), so a report saying "this number was three days old" is useful, not annoying.

What this repository is not: a support channel for OpenAI or Anthropic products, and not a place for vendor promotion.
